# Política de Privacidade - ETTJ DI1

**Última atualização:** Janeiro de 2024

## 1. Introdução

Esta Política de Privacidade descreve como o aplicativo ETTJ DI1 ("Aplicativo") coleta, usa e protege suas informações. O Aplicativo foi desenvolvido pelo Prof. José Américo (Coppead/FGV/UCAM) exclusivamente para fins educacionais.

Ao utilizar o Aplicativo, você concorda com os termos descritos nesta política, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

## 2. Dados Coletados

### 2.1 Dados que NÃO coletamos
O ETTJ DI1 foi projetado com privacidade em mente. **NÃO coletamos:**
- Informações pessoais identificáveis (nome, e-mail, telefone)
- Dados de localização
- Informações de contatos
- Dados biométricos
- Histórico de navegação
- Identificadores de publicidade

### 2.2 Dados armazenados localmente
Os seguintes dados são armazenados **apenas no seu dispositivo** e nunca são transmitidos para servidores externos:
- Preferências de configuração do aplicativo (tema, método padrão)
- Última data consultada
- Cache de dados para melhor desempenho

### 2.3 Dados de mercado
O Aplicativo acessa dados públicos de contratos futuros DI1 da B3 (Brasil, Bolsa, Balcão) através da biblioteca pyield. Esses dados são de domínio público e não contêm informações pessoais.

## 3. Uso dos Dados

Os dados armazenados localmente são utilizados exclusivamente para:
- Melhorar a experiência do usuário, mantendo suas preferências
- Otimizar o desempenho do aplicativo através de cache
- Permitir o funcionamento offline básico

## 4. Compartilhamento de Dados

**Não compartilhamos seus dados com terceiros.** O Aplicativo:
- Não utiliza serviços de analytics
- Não exibe publicidade
- Não vende ou comercializa dados
- Não transmite informações para servidores externos, exceto para obter dados de mercado públicos

## 5. Segurança dos Dados

Implementamos medidas técnicas para proteger seus dados:
- Armazenamento local criptografado quando disponível pelo sistema operacional
- Conexões HTTPS para comunicação com APIs
- Nenhum dado sensível é transmitido pela rede

## 6. Seus Direitos (LGPD)

Em conformidade com a LGPD, você tem direito a:

### 6.1 Acesso
Você pode visualizar todas as configurações armazenadas no aplicativo através da tela de Configurações.

### 6.2 Correção
Você pode modificar suas preferências a qualquer momento nas Configurações.

### 6.3 Exclusão
Você pode excluir todos os dados armazenados através da opção "Limpar Cache" nas Configurações, ou desinstalando o aplicativo.

### 6.4 Portabilidade
Você pode exportar suas configurações em formato JSON através das Configurações.

## 7. Crianças

O Aplicativo não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente dados de menores.

## 8. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações significativas serão comunicadas através do próprio aplicativo. A data da última atualização está indicada no início deste documento.
