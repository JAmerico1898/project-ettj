# Assets

This folder should contain the following image files:

- `icon.png` - App icon (1024x1024 px recommended)
- `splash.png` - Splash screen image (1242x2436 px recommended)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

## Temporary Setup

Until proper assets are created, you can use placeholder images.

### Quick Setup with Expo

Run `npx expo install expo-asset` and create simple colored squares as placeholders,
or download sample assets from the Expo documentation.

### Recommended Tool

Use https://easyappicon.com/ or similar tools to generate all required sizes from a single image.
